About

Analytics with the definitions, limits and evidence written down.

I'm an MSc Scientific Computing with Data Science graduate based in England, United Kingdom, with hands-on experience in Python, SQL, machine learning and generative AI. My work centres on predictive modelling, RAG workflows, data pipelines and data quality — with a focus on reliable, reproducible AI solutions rather than one-off notebooks.

My scientific computing background trained me to treat data carefully: validate inputs, document assumptions, state limitations, and make results reproducible. I care about the unglamorous parts — lineage, quality checks, evaluation — because that is what makes a model something a business can actually rely on.

That instinct is why Sage caught my attention. A business built on accounting, payroll and finance runs on numbers people have to be able to trust, and Sage's agent work — reading incoming bills, flagging unusual journal entries, tracking month-end close — is only as good as the data quality and evaluation behind it.

  • Structured + unstructured data: OCR and document-extraction pipelines alongside SQL and BigQuery work.
  • Generative AI in practice: RAG, LLM-based search and prompt engineering applied to real document workflows.
  • Classic ML foundations: classification, regression, clustering and feature engineering with scikit-learn.
  • AWS-oriented: AWS re/Start, AWS Data Analytics and AWS Technical Essentials certified.
  • Evaluation mindset: data validation, quality checks and model evaluation built into every project.
  • Reproducibility: Docker and Git used to make data-processing workflows maintainable.
